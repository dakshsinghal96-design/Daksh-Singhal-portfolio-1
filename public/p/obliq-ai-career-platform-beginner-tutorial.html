1. Quick Start Guide

This section is for someone who wants to try the app immediately without reading the full document first.

  1. Open Obliq-AI-Career-Platform.html in a browser.
  2. Click the intro screen to enter the app.
  3. Select your role, usually Student for the main journey.
  4. Use the login or register screen to continue through the demo flow.
  5. Choose a language and accept the consent and privacy screens.
  6. Complete the profile form with class, age, city, stream, subjects, marks, and career dreams.
  7. Select interest cards that match what you enjoy.
  8. Choose an assessment mode and begin the assessment.
  9. Answer the questions honestly. Some questions use options, ratings, rankings, or short text.
  10. Complete optional portfolio and parent input sections.
  11. Wait for the AI processing screen to finish.
  12. Review career results, stream guidance, courses, colleges, budget, roadmap, chat, report, and dashboard.
  13. Use Download / Print Report to print or save the report as a PDF.
Simple rule: The app is designed to help you explore better choices. It should not be treated as a final authority. Important education and career choices should still be discussed with parents, teachers, counsellors, or mentors.

2. Overview

Obliq AI Career Platform is a web-based career counseling prototype. It helps a student understand possible career directions by combining profile information, interest choices, assessment answers, adaptive questions, parent input, portfolio information, and report generation.

The project is built as a single HTML file with inline CSS and JavaScript. This means the user can open the app directly in a browser without installing a backend server. The app stores demo data in the browser using localStorage, so progress can remain after refreshing the page.

The main purpose is to create a guided career counseling experience that feels modern, visual, and easy to use. It includes student-facing guidance screens, parent and counsellor views, school analytics, admin management sections, a privacy center, and print-ready reports.

Main Purpose

  • Help students discover career paths that match their interests, strengths, values, and preferences.
  • Suggest streams, courses, colleges, and practical next steps.
  • Give parents a simple way to support the student without pressure.
  • Allow counsellors to review reports and add human validation.
  • Provide schools and admins with management and analytics-style prototype screens.
  • Keep privacy, consent, data export, delete options, and AI disclaimers visible.
Important: The system is AI-assisted guidance. It does not guarantee admission, marks, salary, career success, or a perfect personal match.

4. How It Works

This section explains the main workflow in simple steps.

Step 1: The User Enters the App

The user sees the intro screen and clicks anywhere or presses Enter/Space. The app then moves to the welcome screen. The intro is decorative but also sets the tone for the product.

Step 2: The User Chooses a Role

The role controls the path. A student enters the full assessment journey. Parent, counsellor, admin, and school roles open their own dashboards or management screens.

Step 3: The App Collects Consent

The consent screen explains what the app does with user information. The app stores consent records in the local demo state and audit log.

Step 4: The Profile Is Saved

The student profile includes items such as age, class, city, board, current stream, subjects, marks, dream career, and confusion level. This information helps personalize the results.

Step 5: Interest Cards Are Selected

Interest cards help the app understand natural preferences before formal assessment begins. For example, a student may select technology, design, healthcare, law, sports, business, or other interest areas.

Step 6: The Assessment Starts

The app builds a fresh assessment set from its internal question bank. Questions are shuffled and tracked so the same user does not always receive identical questions in the same order.

Step 7: The Student Answers Questions

Answers are stored in the app state. Some answers add weight to career clusters such as healthcare, technology, business, creative, humanities, physical, or broad exploration.

Step 8: Adaptive and Validation Logic Runs

If the user's answers strongly point to a cluster, the app may ask an adaptive follow-up question. If the student's dream career conflicts with the strongest result, the app may ask a validation question to decide how to treat the dream career in the report.

Step 9: Optional Portfolio and Parent Input Are Added

The portfolio screen lets the student describe projects, achievements, or interests. Parent input can include budget, city preference, college type, abroad comfort, support style, and concerns.

Step 10: The Processing Screen Builds the Result

The processing screen shows messages such as reviewing responses, mapping personality, matching careers, and composing the report. Behind the scenes, the app computes results and prepares the guidance screens.

Step 11: Results Are Displayed

The app shows top career matches with fit percentages, reasons, stream suggestions, course options, college options, budget details, and a 90-day roadmap.

Step 12: The User Continues with Dashboard, Report, and Chat

The dashboard helps the user keep track of progress. The report can be printed. The AI mentor chat gives basic guidance based on the stored result. The user can also export or delete data from privacy screens.

Data flow in simple words: User input goes into the app state, the app scores the input, results are generated, and screens render those results. The browser saves the state with localStorage so the demo can continue after refresh.

5. How to Use It

5.1 Setup

  1. Keep the app file named Obliq-AI-Career-Platform.html.
  2. Keep any referenced asset folder, such as assets, beside the HTML file if images are used.
  3. Open the HTML file in a modern browser such as Chrome, Edge, or another Chromium-based browser.
  4. No backend server is required for the basic demo because the app is a single-file HTML/CSS/JS prototype.

5.2 Everyday Student Use

  1. Open the app and enter from the intro screen.
  2. Select Student.
  3. Complete login/register flow.
  4. Choose language.
  5. Read and accept consent.
  6. Fill profile honestly. Avoid guessing marks, subjects, or dream career if unsure.
  7. Select interests that genuinely feel exciting.
  8. Choose assessment mode.
  9. Answer all questions calmly and honestly.
  10. Use Focus and Calm Mode only if comfortable giving permission.
  11. Review results with a parent, teacher, or counsellor.
  12. Use the 90-day plan for action, not just reading.

5.3 Parent Use

Parents can use the parent dashboard to understand the student's top guidance in a simple format. Parents can also provide input about budget, preferred city, college type, abroad comfort, support style, and concerns.

The best parent approach is supportive, not forceful. Use the report to start a conversation instead of making an instant decision.

5.4 Counsellor Use

Counsellors can review student reports, update review status, and add notes. This is important because human validation can catch nuance that a prototype scoring system may miss.

5.5 School Use

The school dashboard is designed for institution-level insight. It can show student overview, stream distribution, counsellor allocation, parent meeting support, and analytics-style sections.

5.6 Admin Use

The admin panel is a prototype management area. It includes users, question bank, career database, course database, college database, report builder, AI settings, pricing, coupons, schools, counsellors, analytics, feedback loop, and audit logs.

5.7 Printing or Saving a Report

  1. Complete the assessment journey.
  2. Open the report screen.
  3. Click Download / Print Report.
  4. Use the browser print dialog to print on paper or save as PDF.

5.8 Resetting Demo Data

The app has a reset option that clears demo data from the browser and reloads the app. This is useful when testing with a new student profile.

6. Practical Examples

Example 1: Class 10 Student Choosing a Stream

A Class 10 student is confused between Science and Commerce. They complete the assessment and the app shows strong technology and analytical signals. The stream guidance suggests Science PCM as the primary path and PCMB as backup. The student then views courses, colleges, and a 90-day plan for coding, math practice, and career interviews.

Example 2: Student Has a Dream Career That May Not Match

A student enters "Doctor" as a dream career, but their answers point more strongly toward creative design. The app asks a validation question: should the dream career be prioritized, kept as backup, or replaced by best-fit careers? This gives the student control instead of ignoring their dream.

Example 3: Parent Wants a Practical College Plan

A parent adds budget range, preferred city, and college type. The final report includes parent input and the college section can be filtered by India, abroad, online, certifications, budget, eligibility, exams, and scholarships.

Example 4: Counsellor Reviews an AI Report

A counsellor opens the counsellor dashboard, selects a report, adds notes, and marks it as approved or needing follow-up. This keeps the app human-centered and avoids relying only on automated guidance.

Example 5: School Uses Group Insights

A school can view stream distribution and student guidance summaries. This can help plan parent meetings, counsellor allocation, workshops, and stream counseling sessions.

8. Best Practices

For Students

  • Answer honestly, not according to what sounds impressive.
  • Do not rush the assessment.
  • Use the report as a conversation starter.
  • Compare top careers instead of focusing only on the first result.
  • Follow the 90-day roadmap in small steps.

For Parents

  • Ask open-ended questions such as "What feels interesting about this path?"
  • Avoid forcing a career based only on salary or social status.
  • Discuss budget and location honestly.
  • Encourage exploration before final decisions.
  • Use counsellor review for important choices.

For Counsellors

  • Review both the results and the student's written context.
  • Look for contradictions between interests, values, and family constraints.
  • Add human notes that explain why a recommendation should be followed or adjusted.
  • Remind users that AI output is guidance, not guarantee.

For Schools and Admins

  • Keep question banks clear and age-appropriate.
  • Review career, course, and college data regularly.
  • Use audit logs for accountability.
  • Do not collect more personal data than needed.
  • Make consent and privacy policies easy to understand.
